## 站点清洗、参数来源与局限

站点空间清洗后状态：{'land': 289, 'excluded_duplicate': 1}。。样本选取是在 NOAA 高风报告候选和 METAR TS/CB 检查后进行，并非盲样；不应将 5 个筛选事件外推为 2018–2024 年总体。

| 参数 | 来源/性质 |
| --- | --- |
| NOAA 事件分类/日期 | NCEI 年度 details CSV，本地时刻按州 IANA 时区换 UTC，边界附近有时区/县区误差风险 |
| METAR 持续风与阵风 | Iowa Environmental Mesonet ASOS 下载，sknt/gust 分列，kt×0.514444 m/s；逐事件 IEM URL 清单 |
| ERA5 10 m 风 | ARCO-ERA5 小时 10m U/V 双线性站点插值后求模；再分析非实时预报；格点到机场观测存在代表性差异 |
| WorldCover | ESA WorldCover 2021 v200；Planetary Computer 1 km 圆域主类，亦复用 H2 同站已核类别 |
| coverage | assumption >=75% of 25h and report within ±2h regional median peak；除数据源口径外均为本轮假设/沿 H2 比较设置 |
| QC | assumption 0–120 kt mean, 0–150 kt gust; gust>=mean；除数据源口径外均为本轮假设/沿 H2 比较设置 |
| IDW | assumption power 2；除数据源口径外均为本轮假设/沿 H2 比较设置 |
| OK | assumption exponential range 75 km nugget .08; empirical 25km bins to 300km, 20–300km fit; fallback 75km；除数据源口径外均为本轮假设/沿 H2 比较设置 |
| ERA5 | ARCO hourly 10m u/v interpolated to station then magnitude；除数据源口径外均为本轮假设/沿 H2 比较设置 |

时间筛选局限：同州 Storm Events 排除 Thunderstorm Wind，而空间框可能伸入邻州；五例在本研究区域 METAR 无真实 TS/CB token，但仅排除公开报告和站点可见雷暴，不能证明整片区域绝对无对流。峰值截尾仍可能发生于符合 75% 覆盖的站，机场站代表性不等于地面损失点。逐事件最优方法在该事件数据上选择，可能乐观；ERA5 分析场并非实时预报。

## 结论

五事件合计（433 站）ERA5+残差固定 OK 相对 OK 拟合：峰值 RMSE 2.318→2.243 m/s，降低 3.24%，247/433 站改善；峰值 bias −1.399→−1.245 m/s，低估略减；按预定判据为“插值够用”。

勘误（筛选口径，不重算预测）：原始 `raw_metar_ks_20180306_h3.csv.gz` 中 OK:AVK 于 2018-03-06 14:15 UTC 报 VCTS（`KAVK 061415Z AUTO 29014KT 10SM VCTS CLR … LTG DSNT Nks_20180306`“合规”均错误，该事件依 不合规，五事件合计仅为历史口径，不作严格合规结论。由 `peaks_h3.csv(+|-|VC)?TS(RA|GR|...)?`（排除 `TSNO`），云量 CB 按；该识别规则为本次勘误建议，并非已重跑 H4。
