# H 良态风站点留一重建 r1：QC2 有效结论

本文件以 和 为有效结果。首次计算的 、 和 `predictions_r1.csv.gz` 含三条畸形 METAR（GYI 134 kt、CNW 两条 121 kt），**作废、勿引用**；遵守不覆盖既有结果的约束而保留。 是 QC 前初稿，修订计数见。

## 判据与一句话结论

事先判据：最好的背景+残差或学习方法相对 IDW/OK 较优者 RMSE 至少降低 20% 且至少 2/3 站改善 → 值得继续；10–20% 或仅一项 → 有条件；小于 10% → 插值够用。此筛选不等于论文结论。
总体：OK 1.613 m/s；最优梯度提升树+残差 OK 1.524 m/s，下降 5.50%（逐日 bootstrap 95% 区间 3.90%–7.16%）；改善 87/137 站，未达到 2/3。按事先判据：插值够用；但 >50 km 稀疏站距子组增益值得另行检验。

## 样本、数据、方法

10 个良态大风 UTC 日、240 小时、137 个实际受评站、31,898 站时样本；145 个候选站。最近站距按该小时有有效观测的其它站计算。所有分数使用完全相同的目标站小时集合。地面小时真值为最近整点 ±30 min METAR（非 1-min 平均）；knots × 0.5144444444444445；仅去除站点值超过 40 kt 的明显畸形报文，未修改其它报文。IEM 声明其原始归档只做有限 QC。[1]

ERA5 从 Google Research ARCO-ERA5 0.25° 小时 10 m U/V Zarr 对站点双线性插值；HRRR 从 NOAA AWS S3 `wrfsfcf01` 10 m U/V GRIB2 消息按字节范围取数，用网格最近点；目标 UTC 小时使用前一小时初始化的 f01，不使用 f00。[2][3]

IDW 用球面距离 1/d²；OK 对当小时其它站建指数协方差 C(d)=exp(-d/75 km)，对角加 0.08 nugget，常数未知均值约束；矩阵逆对角恒等式一次求所有单站严格 LOO 预测。背景+残差对每小时其它站的“观测风速 - 该站模式风速”做同一 OK。学习法 HistGradientBoostingRegressor 对每一个待检站单独训练，跨全部十日严格排除该站，特征 ERA/HRRR U/V、站点高程、经纬度、小时正余弦；加残差 OK 时对其它站模型训练内的残差做当小时 OK。GBDT 参数是预先固定的小模型，未调参。风速独立建模，故学习法无 u/v/风向预测。

## 参数来源与可疑点

| 参数 | 取值 | 来源或假设 |
| --- | --- | --- |
| 站点地理范围、观测单位 | 28–34°N，94–100°W；knots | 任务书；IEM API 字段定义[1] |
| METAR 整点代表 | 最近整点 ±30 min | 假设，日内标准 METAR 多在 :53–:55；与逐时再分析配准 |
| 强风日阈值及无对流排除 | ≥10% 站时 ≥8 m/s，≥60 站，区域 METAR 无 TS/VCTS/CB、全州 Storm Events 无 Thunderstorm Wind | 任务书“相当比例”未给数，10% 为事先固定假设；NOAA 数据源[4] |
| 极端风 QC | >40 kt 排除 | 假设；三条异常原文 `160134KT140121G18KT` 不合常理，超过并伴错误格式；仅排这三条，低风速和其他潜在误码未进一步处理 |
| HRRR 时效 | f01，目标小时前一小时初始化 | 任务书禁止 f00；AWS idx 实测包含 `1 hour fcst`，脚本可核对[3] |
| HRRR 站点映射 | 网格最近邻 | 假设；避免 Lambert 网格重网格插值；会留下几 km 代表性误差 |
| IDW 幂 | 2 | 假设，经典距离平方反比，不做事后优化 |
| OK 变差函数/相关长 | 指数，75 km，nugget 0.08 | 均为预先固定假设；**未按日/小时拟合经验变差函数，不完全满足任务书此项**；同样作用于纯 OK、背景残差 OK、学习残差 OK，结果对长尺度敏感 |
| GBT 超参 | 80 树、12 叶、学习率 0.06、L2=5 | 假设的小 CPU 模型；不以验证集调参，避免站点泄漏 |
| 自助法 | 10 日有放回抽样 2000 次，随机种子 2718 | 假设；日数少，相邻天气过程相关，区间可能偏窄 |

## 局限与后续判断

1. ERA5 是再分析、可能含同一观测网络历史同化；HRRR f01 虽非同小时 f00，同化的前一小时站点资料仍可能影响该预报；两者都不是严格“完全无站点信息”的独立背景。
2. GBT 使用同一天其他站观测训练，实际对待检站全十天保持完全隔离；“GBT+残差”在训练站上用模型的训练内残差，非交叉拟合，可能乐观。
3. 未按日/小时拟合变差函数，也未扫描 IDW 幂次；这限制“最好的纯插值”称谓，只能说比较了两个预先固定的强基线。>50 km 子组占少数且地形/站型组成可能不同；不能从该子组推断普适增益。
4. 高程来自 IEM 站表，未引入真实 NLCD；METAR 实际传感器高度未逐站核证为 10 m；风速以整数 knot 报告、非小时平均。
5. 筛选依据 METAR + 已登记雷暴风，仅排除显见对流；Storm Events 以当地日期而 METAR 以 UTC 日筛选，跨日边界可能残余误分类。
6. 更完整的后续：训练站互斥的日/站变差函数敏感性、严格无站同化背景、按日期外推验证以及每日最大值指标。当前按预定总体判据不建议直接扩大到全域融合项目。
