## 阵风、站距与孤立峰

一分钟 gust_sknt 为独立 5 秒阵风量；ERA5 10m U/V 是持续风背景，没有相同定义的阵风背景。故阵风只能报 IDW/OK 阵风对阵风，不对“ERA5 阵风融合”套主判据；这项是预设对比未能执行的缺口。孤立峰定义为本站事件内观测持续风峰值高出同事件其他所有可评站峰值至少 5 m/s，不等同同一分钟孤立峰或下击暴流证据。

## 清洗和参数来源

ASOS1MIN 网络在目标框共14站。H2/H3 的站点清洗规则重新应用：WorldCover 2021 v200 站点周边1 km主类，水体或平台另池，未知类保守不入，T89 坐标疑点排除，<2 km 连通对保留五事件累计有效分钟最多者。本次14站均为陆地、未发现<2 km站对，详细见。每事件低于75%双变量覆盖的站不评分，但它已有的分钟值仍可当别站输入；无资料者不参与任何拟合。

| 参数 | 来源/性质 |
| --- | --- |
| 雷暴事件及 UTC 报告 | NOAA NCEI Storm Events details， 精确版本 URL；Texas 按 America/Chicago 时区换 UTC；研究区框和挑选规则来自任务书/本轮预登记 |
| 分钟持续风 sknt、5秒阵风 gust_sknt | IEM ASOS 1-minute，逐事件 URL 文件；kt×0.514444 m/s；不与小时 METAR 混合 |
| 小时 METAR | IEM ASOS archived METAR，仅报告覆盖对照，逐日下载 URL 文件；不是主评分 |

| WorldCover | ESA WorldCover 2021 v200 via Microsoft Planetary Computer 1km 主类，或复用 H2/H3 已有同站类别 |
| IDW/OK | 假设：IDW 幂2；OK 指数协方差75 km、nugget .08；拟合：训练站小时风中位数经验变差函数25 km箱、20–300 km拟合，样本稀缺时回退75 km。逐分钟留一目标站不参与拟合 |
| 覆盖及 QC | 假设：361个分钟至少271分钟同时有有效持续风和阵风；≥4个其他同分钟站才预测；持续风0–120 kt、阵风0–150 kt，阵风≥持续风。详细断报见 metrics_h4v3.json |
| HRRR f01 | 未下载/未评分；上游分析已同化站点，即便f01也不作独立留一证据 |

限制：只有14个具1分钟档案站、四个可评事件共44站事件；2025-03-04 虽有87条 Storm Events 报告，但区域一分钟档案只有5站满足覆盖要求，不能凭小时 METAR 填补分钟峰。雷暴尺度峰位可在站间移动，站点峰不是连续场真值。事件窗口由全站观测定，事件/方法择优会乐观，阵风融合比较缺失；小时 vs 分钟支持集不同，不能套用 H2/H3 数字。此处孤立峰计数为零仅是“高出所有其他站峰值”的严格定义下的结果，不证明没有局地极值。

## 结论

四个可评事件合计，持续风事件峰值最佳纯插值 IDW 4.776 m/s，ERA5+固定残差 OK 4.786 m/s（恶化0.19%），26/44站绝对误差改善；峰值 bias −3.245→−3.330 m/s。按开算前判据为“插值够用”。纯插值阵风峰值最佳 OK75 RMSE 6.848 m/s、bias −5.079 m/s；ERA5 阵风融合未能同量比较，不能称“阵风融合插值够用”。
