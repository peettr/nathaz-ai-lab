# Storm Events r1b：风速单位换算与站点语义评分修正

范围仍为主样本 300 条、独立金标准 60 条（雷暴/热带/High Wind 各 20），不重跑 Gemini；原始 r1 报告与 原样保留。重算执行，新机器输出，300/300 ok、60/60 有可评分答案。评分脚本把 mph、kt（knots）和 m/s 统一到 m/s，以 ±0.5 m/s 判单值；金标准区间的两端先换算再各扩 ±0.5 m/s。未知单位的非空速度不可判对。站点原字符串精确档不动，另加小写去空格后互相包含的语义档（只是宽松别名近似，不是权威站点 ID 解析）。

857631 的模型 59 kt 对金标准 68 mph，换算后在容差内，现判正确；不再列入失败例。r1 的其他叙述风速失败例 924082（AWOS 37 mph 与 35–45 mph 另一个风速）、913730（代理推测值）仍需区分。原 r1 对 857631 的失败说明还称模型输出 59 mph，与保存的实际答案/委托说明不同；以 和新机器评分为准。雷暴 20 条金标准的速度和来源几乎都是空值，不能把 20/20 当正例能力。

结论：纠错仅改变热带风速值一题；热带站点语义分由 12/20 提至 15/20，其余 r1 结论不变。来源准确率和同地同时独立风速配对仍待 r2 的困难金标准与 DAT/IEM 实测验证。
