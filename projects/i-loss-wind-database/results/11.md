# Storm Events 叙述抽取规则 r1

来源：NOAA NCEI Storm Events 2018–2023 年 details CSV，逐年文件和 SHA256 见；NWSI 10-1605 (2021) https://www.weather.gov/media/directives/010_pdfs/pd01016005curr.pdf。模型输入仅 EVENT_NARRATIVE（不暴露 MAGNITUDE / MAGNITUDE_TYPE / SOURCE / DAMAGE_PROPERTY），地点、时间、event_id、hazard 在输出表由结构化列确定，不拿模型猜测。

| 字段 | 规则 |
| --- | --- |
| event_id, hazard, date_time_local, location | 外部 CSV EVENT_ID、按 EVENT_TYPE 归类、BEGIN_DATE_TIME + CZ_TIMEZONE（本地标准时间，不转 UTC）、STATE/CZ_NAME/BEGIN_LOCATION/BEGIN_LAT/BEGIN_LON；不评价模型对此的准确率 |
| structure_type | 叙述明确受损的对象集合；house, mobile_home, commercial, barn, power, tree, vehicle, sign, other；未指明为空。power 含 pole/lines；不把失电自动等价电杆损伤 |
| damage_description | 叙述原文摘句，必须逐字子串；无损伤句为空 |
| damage_severity | none/minor/moderate/severe/destroyed；仅据文字，不按财产损失数值反推。多处以最严重为准；损坏但无程度→moderate（操作性假设） |
| wind_speed_value, wind_speed_lower, wind_speed_upper, wind_speed_unit, wind_speed_mps | r1 遗留单值字段保留可比；r2 另增 `wind_observations` 数组，叙述中每个事件现场数值/区间各一条，列全而非取最大值，保留站点、时刻、速度类型、来源及证据原文。区间（如 50–60 mph）保留下上界，评分时换算至 m/s，落在区间扩 ±0.5 m/s 内算对；mph×0.44704、kt×0.514444。预报/阈值/一般风暴最高风速不列为现场观测；代理观测列出并标注 proxy，不作为实测损失配对 |
| wind_speed_kind | gust/sustained/unknown/none；原文点明阵风或持续才赋值 |
| wind_speed_source | measured/radar/damage_inferred/observer_estimate/estimated_unspecified/none。仪器明确实测 measured；雷达估计 radar；明确按损伤或 EF/DI/DOD 推定 damage_inferred；有人目测且未提损伤 observer_estimate；仅 estimated、没有依据 estimated_unspecified；叙述中无任何事件现场风速及其来源 none。多种来源时以被抽取风速对应来源为准；原文不明时不把损伤与估计的共现自动判成 damage_inferred |
| wind_speed_source_quote, instrument_or_site, ef_damage_rating | 支撑来源的原文精确片段、仪器/站点名称、明确 EF/DI/DOD 等级；无据则空 |

r2 边界：代理站/雷达或别处风速即使实测也不能当损伤位置的实测；若原文明确说代理推测而非当地值，`wind_observations` 中标 `proxy=true`，不计严格同地配对。叙述仅有停电（power outage）而无电线、电杆、变压器或建筑物实际损坏，受损对象集合为空、severity=none；停电不能当 `powerprimary_source` 只是兼容六分类评分的选中风速来源，不能代替全表。

后处理另建 `source_joined`：当模型/人工叙述来源为 none 或 estimated_unspecified 时，若 MAGNITUDE_TYPE=MG/MS，归 measured；若 EG/ES 且该条有结构化 MAGNITUDE，归 estimated_unspecified；不能从 EG/ES 推定按损伤反推。叙述中明确 damage_inferred 优先于 EG，但与 MG/MS 冲突标记待审，不默认改写。EG 中分别统计叙述能明确确认依据的数量（measured/radar/observer_estimate/damage_inferred）及能明确确认损伤依据的数量，EG + 仅有损伤描写不算。非损伤两档分子：严格 measured+radar；宽松再加 observer_estimate。分母同时给全部样本与有结构化或叙述风速的样本；estimated_unspecified 不纳入任何分子。叙述风速出现率与结构化 MAGNITUDE 非空率按灾种分开报告。2010–2017 S1 四城补充批 40 条与主样本独立汇报，不合并主 300 准确率。

## H 重建值配对扩展（C；协议 v1.2 §3–4）

当前 DAT–IEM 小试只使用 IEM 实测阵风，未调用 H；以下字段仅在以后实际接入 H 重建值时逐条必填，不用协议中的样本均值冒充损伤点的预测值。重建配对与实测配对分表、分开计数，重建不计入严格独立风速档；雷暴不使用 H 重建。飓风事件最大风用 Holland+残差克里金，不能从普通克里金时程取最大值；逐小时时程若用普通克里金，须注明它不作为最大风估计。

| 字段 | 填法与边界 |
| --- | --- |
| wind_speed_source | `reconstructed`，不得填 `measured`；仅属配对表扩展，不改变六分类叙述来源标签 |
| reconstruction_method, background_field | 实际方法及背景场名称；例如 Holland+残差与其实际使用的 Holland 场，不凭方法名称猜背景版本 |
| peak_definition, peak_window_start_utc, peak_window_end_utc | P1=观测峰时刻预测误差（只有有观测峰时刻的验证样本才适用）；P2=共同有效时刻窗口最大值，飓风登陆 ±12 h，温带区域峰 ±12 h，雷暴 ±3 h；损伤点无测风仪时不得宣称 P1 峰值真值；记具体 UTC 起止及定义来源 |
| wind_quantity, averaging_interval | 持续风或阵风；注明 METAR 小时报持续风约 2 min、阵风约 5 s；若使用别的档案原始定义未核实，标 `unknown`，不得混比 |
| nearest_input_station_km, event_type, hurricane_center_distance_km, hurricane_rmw_km, hurricane_rmw_bin | 记录实际输入站最近距离、事件类型；飓风另记中心距、RMW 及 `<11–3>3 RMW`，中心距或 RMW 不可得则标 `unknown`，不代填外围档 |
| validation_subset, sample_rmse_mps, sample_bias_mps | 只引用与方法、风速量、峰值定义、事件类型及 RMW/强风子集相符的留出样本数值；偏差=预测−观测；显式注明“样本统计，非逐点保证”；不适配则空值并解释 |
| colocated_independent | 固定 `false`，H 重建不进入严格独立档；与实测邻站候选亦分开计数 |
| reconstructed_raw, peak_correction_mps, peak_correction_version, reconstructed_corrected | `reconstructed_rawpeak_correction_mps` 记录实际施加的有符号加性校正，未校正填 0 而非缺失；`peak_correction_version` 记 `v1.2`；`reconstructed_corrected = reconstructed_raw + peak_correction_mps`。校正值标“重建、非实测、已校正（v1.2）”；零校正的飓风值应另明确标“不施加峰值校正”，不得暗示加性校正提升精度 |

按事件类型、风速量、方法和峰值口径分别选择校正量，禁止跨类通用。协议 v1.2 §4：良态持续风推荐法 P2 为 +0.82 m/s（不是 §1 的 P1）；温带持续风 OK 拟合 +1.46 m/s、阵风 OK 拟合 +1.38 m/s；雷暴持续风 IDW +3.25 m/s、阵风 OK 固定 +5.08 m/s（仅四个达拉斯事件，单事件残余偏差可达约 ±2–3 m/s，粗估，且本试验雷暴配对仍不用重建）；飓风 Holland+残差持续风和阵风均不校正（ §0–4；该协议 §1、§4 给出原始证据路径。

## H4/H2 跨节点只读配对及空间足迹（r2 补充）

新增逐点 `footprint_context`：NOAA JetStream《Thunderstorm Hazards - Damaging Wind》“Microbursts and Macrobursts”（网页无页码）给微下击暴流出流直径 <4 km、下击暴流范围至 10 km；Romanic、Taszarek、Brooks (2022), *Weather and Climate Extremes* 37:100474，摘要/期刊第 1 页给微/宏下击暴流损伤风水平尺度 4 km 分界。因此站点距点 ≤4 km 只是空间上可能；4–10 km 已超单个微下击暴流直径但宏下击暴流或阵风锋仍可能，10–25 km 超出典型单一下击暴流范围，不应以邻站峰值替代该点峰值。DAT 记录并未逐点确认为下击暴流：以上只是尺度风险标签，不是事件机制归因；风暴平移、站点高度/暴露和时间差另需核验。

飓风站点–损伤点需有该时刻中心距与 RMW 才能判 `<11–3>3 RMW`；若无点位对应 RMW，`rmw_bin=unknown`，不可将 H2 邻站的 RMW 档冒充损伤点档。H2 `grid_*colocated_independent=false`（尚未验证同地同刻）；重建单列且严格独立档永不计入。雷暴仅用 H4 一分钟 `gust_sknt`（5 秒阵风）与其预存 UTC 窗口，不混小时 METAR，也不重建；H2 热带只读陆地站表，阵风用 IEM 已缓存 METAR 小时档，与 H4 的分钟档不能直接比较捕捉峰值能力。
