## 4. 对今晚 CRC 作业 `1536823`（西风、1 m 网格）的定量预言

今晚运行的作业 `1536823` 配置文件为 （`resolution = 1.0angle = [270]`，`run_nstep = 100000`，`purge_avg = 50000`，未修改 `pad_x_factor = 2.0` 与 `setup.cpp`）。

### 4.1 主要偏低机制在 1 m 网格下会不会消失？
- **明确结论**：**部分消失（不会完全消失）**。
- **详细理由与定量依据**：
 1. **为何会“部分消失”（使 80 点均值从 `0.217` 大幅跃升至 `0.28 – 0.34` 的三个机制）**：
 - **机制 A（竖向采样层位跳变至第 3 层流体，彻底摆脱第 1 层流体拖曳）**：在 `1536823` 中， 第 `631996voxelize_mesh` 的 `(ushort)` **向下截断为 `20`（而非 `21`）**！因此平地最高固体层为 $k_{\text{solid\_top}} = 19$，反弹壁面位于 $k_{\text{wall}} = 19.5$，第 1、2、3 层流体分别为 $k = 20, 21, 22$。而后处理提取 $Z_{\text{VTK}} = 2.0\text{ m}$ 时的下标为 $k_{\text{VTK}}(2\text{ m}) = 22.0 / 1.0002505 = 21.9945 \approx 22.0$，**99.5% 权重直接落在第 3 层流体格点 $k = 22$（距反弹壁面 $2.495\,\Delta x \approx 2.50\text{ m}$）**，完全避开了受半步反弹直接拖曳的第 1 层（$k=20$）和第 2 层（$k=21$）流体！
 - **机制 B（窄街谷通道阻塞大幅缓解）**：$\Delta x = 1.0\text{ m}$ 使新潟斜交窄街谷（测点距墙中位数 `4.70 m`）具备 `5–10` 格的有效过流宽度，阶梯网格锯齿阻塞显著减弱。
 - **机制 C（`+1.0 格` 错位导致的撞墙测点减少）**：经本地对 `rawbuildings.stlvoxelize_mesh` 精确核算，受固体角点污染的测点数从 `r1` 的 21 个、`r3` 的 6 个进一步减少为 **5 个**（编号 `12, 31, 47, 52, 66`，其 `low_fluid_corners` 分别为 `[3, 2, 0, 0, 3]`，其中仅 `31, 47, 52` 需向上回退至 `above_height_m = [7.01, 7.01, 4.01] m`）。
 2. **为何“不会完全消失”（仍保留约 `-0.04` 至 `-0.12` 的系统性负偏差）**：
 - 作业 `1536823` 仍然保留了 `pad_x_factor = 2.0`（西风入口至街区西缘仍有 `809.0 m` 平地底座，扣除 115 格 = `115.0 m` 的入口 nudging 缓冲区后，仍有 **`694.0 m` 的无驱动光滑反弹平地耗散段**），且仍然开启无近壁阻尼的 Smagorinsky `SUBGRID` 模型。
 - 尽管 $\Delta x = 1.0\text{ m}$ 下近壁高剪切层厚度减薄且采样点上移到了第 3 层流体（$k=22$），但在穿过上游 `694 m0.755` 衰减约 `25%–35%`（降至 `~0.48–0.55`），使街区内部 80 个测点的模拟风速比整体均值落在 **`[0.28, 0.34]`（中心估计 `0.31`）**，仍低于风洞西风实测均值（改造前 `0.3540`，改造后 `0.4328`）。
