# 双库与书籍补充试验结论（10-13，美东）

## 范围与方法
只读 Zotero PDF 附件和 EndNote Phd.Data/PDF；未触碰生产库，未纳入 Downloads 其他 PDF。Zotero sqlite 只读 WSL 预先复制副本，EndNote .enl 未解析。沿用前轮 SQLite FTS5 BM25 页索引，在本机增量索引；中文另建 CJK trigram 索引，并在查询时尝试有限的固定风工程中英术语表。未使用新的在线服务、Gemini、GPU/Colab（0 CU）或超算；书籍全文从未外送。新增判据 在增量检索评估前写定，旧 未修改。新增6题均为书籍非首页物理页，含3道中文题；原34道中文题也在扩库后复测。

原先 Zotero 排除书及书章的索引已在本轮补齐，共可检索4501附件、128708非空物理页；来源的 PDF 大小 Zotero 16.53 GiB、EndNote 6.24 GiB。规范化标题/可用 DOI 的候选合并结果为3845簇；EndNote 缺结构化 DOI 且文件名截断，未核实为准确独立文献数。库内PDF附件按 Zotero 父 itemType：book 73、bookSection 26、thesis 50、journalArticle 2870、其他145；和全库 itemType 条目数87/32/60不是同一个口径。EndNote 1517/1527 件无法仅凭文件名可靠分类；其9个“书籍”启发式候选含误判，不可作为真实书籍数量。首页文字启发式判英/中/混/未知详见。159整件无文本附件共10553物理页，但不能据此判定扫描件比例，亦不能直接估 OCR 时间；31件提取失败另计。 更正盘点自动报告中两处过强表述。

## 建议
只保留本地全文检索原型，不据此接入正式 或建设可复用风工程数据集。扩库可行（页面、书籍、中文文本索引均能建）；但书籍内页1/6、跨语中文0/34未过质量门槛。下一步若决定投入，先解码 EndNote 元数据/校正书籍类型和跨库重复，再做多语检索及独立跨页题库；OCR须先抽样扫描页。原下击暴流抽取样表的60项人工核对闸门仍未完成，本补充没有改变它的“不可入库”状态。
