# A2 v3 参数与来源

数据、恒定 q、速度输入、11 点面权重、离线陷波：沿用 v2 params.md 与 run_a2.py；原 CSV SHA256 对照本线。

假设：M=1，m=.05，ζ=.02，频率近训练谱峰和1.4 Hz，控制步长0.1 s；单位为代理无量纲，不是实际楼体。

新控制假设：每步 a²+ηr²+εu²，Q=CᵀC+diag(1e−5,1e−5,η,1e−5)，N=CᵀD，R=DᵀD+ε，a=Cx+Du+F，C=[−k,−c,0,0]，D=−1。Bellman 线性扰动项包括同一步 DᵀF；用离散 DARE 求 P，H=R+BᵀPB，K=H⁻¹(BᵀPA+Nᵀ)，g=Cᵀ−KᵀDᵀ+(A−BK)ᵀPE，核 h₀=H⁻¹(BᵀPE+Dᵀ)，hⱼ=H⁻¹Bᵀ[(A−BK)ᵀ]ʲ⁻¹g。式子来自本脚本二次型 Bellman 推导，无文献背书；此前 v2 的状态权重和前馈遗漏加速度同一步项，不可直接对比其数值。

η/ε 网格分别 (0.0001,.01,1.) / (.0001,.01,.1)，验证窗挑达30%者中力RMS最小的组合；测试不重调。力上限=20×训练风力标准差，未限位自检使用∞；三行程为∞、无约束FB峰值×1.5、×.75。所有限位方案同一反馈/前馈增益；非弹性止挡动量回传与冲量加速度沿用 v2，属于简化假设。折扣=max(0,验证 Pearson r)²，对各提前量插值；对比原始目标与离线声学陷波目标（不声称可在线）。各候选、峰值、裁剪比例和验证技巧见 metrics.json。
