# A2 参数来源与假设

| 参数 | 取值 | 来源/性质 | 依据和检验范围 |
| --- | --- | --- | --- |
| 时间步、切分与 Cp | 0.02 s, 42–642 s；q=0.00127991343 | 本线 | 保留原协议；测试发报 <634 s，提前 ≤8 s |
| 探针与面距 | −30/−25/−20/−15/−10 m，排架 −27.1 m；迎风面 −3 m | 本线 | −33.05 固定边界剔除，x≥−5、z12 剔除 |
| Cp REF 压力与动压 | 因果 100 帧 REF ρ；训练窗恒定 q | 本线 | 16.8 Hz 压力振荡，以因果 2 s 压力平滑；空场同窗 q 缺失，不伪造 |
| 声学模态滤波 | 0.27/.52/.95 Hz，iirnotch Q20 双向 | 频率来自任务书；Q20 与离线方法为假设 | 原始/陷波目标两组敏感性；双向滤波仅离线诊断 |
| 面压力面积权重 | C(y,z)=V(z)+H(y)−V(3.01)，Voronoi 代表宽度；36 m² 归一 | 坐标来自；插值是假设 | 不把 11 点当成完整二维压力场；仅迎风面代理 |
| 质量与尺度 | M=1, m=.05；F=ΣwCp 减训练均值 | 假设 | 无实楼尺度；m/M=.05，未单独扫描，结论仅限本假设 |
| 频率 | 0.08545 / 1.400 Hz | 谱峰根据训练荷载 Welch，远共振选择是假设 | 近/远两档敏感性；前者低于声学带，仅用于代理 |
| 结构阻尼比 | .02 | 假设 | 为轻阻尼原型；未扫描，不是实楼取值 |
| 行程限制 | ±.12 / ±.025 | 假设 | 宽松/紧两档敏感性；无量纲位移 |
| LQR 权重与饱和 | Q=diag(ω²,1,20ω²,.2), R=.08；u_max=2σ_F | 假设 | 固定同一反馈/前馈/完美信号对照；不是经验证的物理执行器 |
| 止挡 | 位置裁剪、向外相对速度非弹性归零、主体接收动量 | 假设 | 冲量计入加速度；真实止挡材料和接触时长未建模 |
| 控制离散步长 | .1 s | 假设，沿用输入历史间距 | 在 50 Hz Cp 上每五帧控一次；未扫离散步长 |

无文献依据的质量、刚度、限位、控制器、力尺度全部明确为假设；上述频率与行程两档是任务要求的最低敏感性，不能声称性能稳健。
