**一句结论（10-14 定）**：搁置。AI 天气预报只能服务小时级慢动作，增量小；秒级近场预视原理上收益大（完美预视降加速度 68–80%），但用稀疏上游探针预测只拿到其 0–17%，瓶颈在来流预测技巧。原因、缺的条件与重启条件见。
