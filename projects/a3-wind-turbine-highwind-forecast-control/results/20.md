## 预定判据

对每一路径，若某一降阈值组偏航峰配对中位降幅 ≥ G2 的 80%，且常规湍流误停率 ≤ G2，则“预视无独特价值，降阈值即可”；否则为“预视有独特价值（以更少误停换取同等降载）”。在 18 个试验的离散误停率上执行原样 ≤ 比较，未事后改阈值。

I_near: 预视有独特价值（以更少误停换取同等降载）
G1L_22: 偏航降幅 13.33% / G2 15.53%；误停 17/18 / G2 10/18；不满足替代判据。
G1L_20: 偏航降幅 23.46% / G2 15.53%；误停 18/18 / G2 10/18；不满足替代判据。
G1L_18: 偏航降幅 14.25% / G2 15.53%；误停 18/18 / G2 10/18；不满足替代判据。
