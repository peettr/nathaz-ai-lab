## 三事件站点格点与 3×3 邻域 CSV

`station_parameters_supp.csvTd_method` 与 `RH03_lower_limit_m`。

站点格点 ERA5 13 层 / 37 层示例：E1 SBCAPE 561.9 / 694.8 J/kg、MUCAPE 561.9 / 694.8；E2 SBCAPE 0 / 0、MUCAPE 191.6 / 193.0；E3 SBCAPE 953.7 / 1006.5、MUCAPE 953.7 / 1006.5。该表是格点值，不能误作前述区域最大值。

气块定义：SBCAPE/SBCIN 为 MetPy `surface_based_cape_cin`，MUCAPE 为 `most_unstable_cape_cin` 默认最低 300 hPa，DCAPE 为 `downdraft_cape`；风切用 10m 风锚定后由 `bulk_shear` 插至目标高度；RH 是可用最低地上等压层至 3 km 的高度积分均值，`RH03_lower_limit_m` 记录截断高度，不是完整 0m 起算 RH。ERA5 的 Td 是原生 2m 露点。两模型无原生 2m Td 输出；CSV `surface_Td_K` 为把最低地上等压层 q（FuXi 由 RH 推得）近似保持至 2m 后，用 2m T、可用压力推算的代理值，ALTU 2023 日期不在原论文所述 Pangu/FuXi 训练期，但镜像逐权重训练谱系仍未核实。
