## 2. 是否跑起来与结论
- **是否跑起来**: **是**（无需降档，UD-IQ4_XS 在 A100-80GB SXM4 + 167GB RAM 上直接完整跑通全套 32K 评测）。
- **一句结论**: **能做到：Strata + Qwen3.8-Flash-Next UD-IQ4_XS 在 Colab A100-80GB (High-Mem) 上可稳定提供 32K 原生全内存驻留推理，32K 针中寻海 100% (3/3) 检索命中，长 Prompt prefill 达 2988 tok/s，decode 达 35–129 tok/s（受 MTP 命中率调控），整体耗费约 5.65 CU，适合作为 ResearchOS 高吞吐本地 Agent 推理后备候选。**

## 8. 实测中发现的问题与边界建议
1. **端口冲突边界**: Colab 默认的 Node.js 平台代理监听了 `8080` 端口，若启动 Strata 服务绑在 8080 会导致 退出（报错 code 2）；必须显式指定 `--port 8090` 或其他未占用端口。
2. **上下文超限防护**: Strata 服务端默认对请求严格校验 `prompt_tokens + max_tokens <= context`，超出即报 400（拒绝截断）。在 32,768 上下文测试中，Prompt 长度需控制在 32,700 以内，或在配置中加入 `"fit_max_tokens": true` 自动压缩输出配额。
3. **MTP 投机解码机制**: Qwen3.8-Flash-Next 搭配的 MTP 草稿层在常规问答中能够将短 Prompt 解码推至 128 tok/s 以上；但当模型生成高复杂度学术专业文本时，投机接受率有所下降，decode 速率稳定在 35–68 tok/s。
4. **硬件与内存搭配**: 80GB SXM4 显存足以装下 62.8 GB 的常驻张量，高配 167GB RAM 确保了 55 GiB 的专家参数直接全量常驻，未发生 SSD 换页降速。
