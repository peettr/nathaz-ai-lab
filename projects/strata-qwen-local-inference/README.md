# Strata + Qwen3.8-Flash-Next 本地推理（Colab A100）

## 目标
在 Colab A100 上实测 Strata（MIT，钉 v0.1.43）+ Qwen3.8-Flash-Next（125B MoE / 6B 激活，unsloth UD-IQ4_XS 约 93.7 GB）：能否跑起来、速度、成本、对我们有什么用。交付：可行性与实测表、日志路径、一句结论（能做到 / 只能做到低档 / 不值得）。

## 当前状态
**结论（10-13 01:20，Lead 核过原始日志）：能做到。** Colab A100 high-mem 上 Strata v0.1.43 + UD-IQ4_XS 不降档跑通 32K；32K 输入首 token 约 10 s、读入约 2,990 tok/s、输出 35–59 tok/s；needle 3/3。代价是**每开一次新 Colab 会话都要约 40 分钟准备（约 4 CU）**，适合"批量处理一批长文档再关掉"，不适合当常驻服务。本轮花费约 5 CU（上限 30）。

## 对我们的用处与不要做的事
- 有用：一次性批量处理长文档（规范、长论文、整批日志，≤32K token/份），数据不出 Google、无按 token 计费；也可做 bot 的离线备用推理。约 4 CU 开机费 + 每小时 5.4 CU，单批几十份长文档才划算。
- 不适合：常驻服务（Colab 会话会断、长时间无输出会断连）；超过 32K 的长文（本次未测）；替代平台主力模型。
- 不要做：不改平台默认模型；API 只绑 127.0.0.1，不开公网隧道；不用 `--dangerously-skip-permissions`；不向第三方提供推理服务（许可第 2 条）。
