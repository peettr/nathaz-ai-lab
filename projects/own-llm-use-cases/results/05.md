- 2a′ 外推/时空场：有成熟通用库（neuraloperator、Transolver，MIT，活跃），可直接在 Colab A100 上做；领域专用仓库（DeepUFNet、FNO-3DUM）星少、许可证缺失或 GPL，只宜阅读评估。

- 3 雷暴风分类：无开源实现，要自建（数据公开、模型小，CPU 即可）；日志判错有成熟 CPU 工具（logparser/Drain3）。
