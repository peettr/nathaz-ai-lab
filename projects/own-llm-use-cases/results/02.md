# TPU 孤立高层风压代理：整栋楼留出最小试验

执行：10-13 06:25（美东）；官方原始数据仅临时保存在 Colab CPU 会话，未向 p14 下载；本地只保留脚本、统计表、图及日志。来源和使用条款见。官网要求引用：TPU (Tokyo Polytechnic University) Aerodynamic Database, 2026, https://db.wind.arch.t-kougei.ac.jp/。官网没有明示开放许可证，故这里仅作内部试验，不再分发原始数据。

## 范围与分割

官方孤立高层案例：T113_4（W:D:H=1:1:3，300 taps）、T213_4（2:1:3，360 taps）、T313_4（3:1:3，320 taps）、T212_4（2:1:2，240 taps）、T214_4（2:1:4，450 taps）。全为 alpha=1/4 的同一入流族。每楼取 0°、10°、20°、30°、40° 五个风向，共 25 个风向–几何案例、8,350 条测点–风向记录；原始时程每文件 32,768 帧、1000 Hz。总原始数据 966,467,013 字节，只在 Colab 临时下载。全库另有更多建筑/风向，本试验不覆盖。

主试验：完整留出 T213_4 的 5 个方向（1800 条点位记录），其他四楼的 20 个案例（6550 条）训练；包括两侧等高宽度邻居与同宽不同高度邻居。B0 在同风向上先按每个立面的面内归一化位置线性插值（凸包外最近邻），再用 T113_4、T313_4 的宽度作 1:1 线性内插；B1 使用四个已知几何相同风向、对齐测点后，固定长度尺度和噪声项的平方指数高斯过程（不调参）；M 是 HistGradientBoostingRegressor，每输出独立训练 120 轮。面号、面内位置、z/H、W/D、H/D、风向 sin/cos 为模型输入。没有目标楼任何压力值进入训练，几何/测点坐标作为预测时已知输入。

辅助试验：在内侧候选方向 10°/20°/30° 中以 重复运行所得六行指标与 完全相同。

## 指标

每格依次为 R² / RMSE（无量纲 Cp）。峰值列特指 32.768 s 原始时程的逐点最小 Cp（负峰），不是 Cook–Mayne 设计重现期峰值；不同楼点数不同，以下为所有测试点的 pooled 指标，不代表跨楼统计显著性。

| 留出 | 方法 | mean Cp R² / RMSE | rms Cp R² / RMSE | 最小 Cp R² / RMSE |
| --- | --- | ---: | ---: | ---: |
| 整楼 T213_4 | B0 几何线性 | 0.9897 / 0.0555 | 0.9268 / 0.0246 | 0.8872 / 0.3778 |
| 整楼 T213_4 | B1 固定核 GP | 0.9884 / 0.0591 | 0.9324 / 0.0237 | 0.9184 / 0.3213 |
| 整楼 T213_4 | M 梯度提升 | 0.9930 / 0.0460 | 0.9344 / 0.0233 | 0.9255 / 0.3071 |
| 随机留出 20° | B0 风向线性 | 0.9842 / 0.0743 | 0.8915 / 0.0349 | 0.9130 / 0.3469 |
| 随机留出 20° | B1 固定核 GP | 0.9963 / 0.0360 | 0.9352 / 0.0269 | 0.8875 / 0.3944 |
| 随机留出 20° | M 梯度提升 | 0.9488 / 0.1339 | 0.6948 / 0.0585 | 0.8951 / 0.3807 |

整楼留出时，M 相比 B0 的 RMSE 降低 mean 17.2%、rms 5.4%、逐点负峰 18.7%；相比 B1 分别降低 22.2%、1.5%、4.4%。所以 mean 和时程负峰有小到中等增量，而最关心的 rms 对 GP 几乎持平；不支持“ML 明显普遍优于简单插值”的宽泛断言。随机留出方向时，M 对 mean/rms 均明显落后 B0/B1，不能将较易切分自动等同乐观分数；模型树对连续风向的插值也会弱于显式物理角度插值。

图 ：留出楼 T213_4、20°、名义迎风面 1 的 mean Cp 实测/B0/M 同色标对比；总体结构均接近，M 有局部平台状平滑。该一幅图只是示意，定量评价覆盖四个表面与全部五方向。图上“nominal face 1”依据 .mat Readme 的立面，不应把 20° 时该立面的实际气动迎风状态推广到其他风向。

文献背景但非直接可比：，PDF p.10 Fig.9 同库干扰楼随机划分 mean/rms R² 高，非新几何；PDF pp.15–17 单楼 CFD 的角度外推 rms R² 0.1291/0.2608，非本次 TPU 相同条件。此次仅一栋插值区间内留出、单一粗糙度、五方向及固定超参数，结论不得外推为通用风压代理可靠性、设计峰压精度或省实验数量。
