# 本地开源 LLM 与 Claude：100 题杂活评测（10-13）

## 结论范围与协议

同一 100 题评测集，A 文献筛选 40（正 10/负 30）、B 论文 PDF 单页抽数 25、C NOAA 事件描述分类 20、D 候选计算器回归比值 15。试验数字均为本线数据，不是论文/规范科学结论。两本地模型用 Colab A100 40 GB 上 vLLM、temperature=0、单题 JSON、10 题一批；Claude Sonnet 经本地 `claude -p --model sonnet --tools ''` 单题调用并发 5。B 给所有模型相同的 `pdftotext -layout` 原 PDF 物理页文本，另以 Docling Markdown 页文本作本地模型变体（只换解析器）。Gemini CLI OAuth，文献不替代本试验。

首版 D13–15 未提供锁值文件却要求背出数值，发现后改为完整给定输入的比值题（eval_set_v2）；首版 C 的示例 JSON 把四个选项写在同一个字符串中，30B 照抄导致 0/20，发现后把选项与单项输出分开，所有参赛模型重新答 C（eval_set_v3）。首版及响应均保留；下表只采用相同 v3 题目/提示的重测结果。执行顺序也有偏离：评测集虽然在首轮调用前已生成并核对 100 题，但没有按任务书先单独回报给委托方再开跑。提示改动在看到首轮输出后发生，不能视为严格盲测；这同时说明格式鲁棒性问题。A 正例标题均含主题词，导致关键词规则满分；这是低难度、非真实召回压力集。

## 每组是否可接走

A：两本地模型均满足自身召回 ≥95%、精确率 ≥Claude 的 70%（8B 100/100、30B 100/90.9）。形式上可接走这个小样本的初筛，但关键词规则也 40/40，且正例标题直接暴露主题；实际建议先用规则，不能据此声称真实数据库筛选达到 ≥95% 召回或让本地排除记录不复核。

B：30B 与 Claude 同为 24/25，达到前沿 90% 的质量线；8B 22/25。Docling 变体没有提升 30B（23/25），预处理反增复杂度。可试为“给定页抽单数值”的候选，但错值/单位仍须源页与程序校验；本任务未设 B 的简单基线，故严格的“明显优于简单基线”条件无法判定，不给无条件接走结论。卡片定量锚点来源和 PDF 页见 与 JSONL 的 `cardpage`。

C：最佳本地 12/20=60%，Claude 15/20=75%，仅其 80%（低于预定 90%）；虽比关键词 8/20 高，仍不满足“可接走”。类别本身可能无法由短叙述唯一确定；需先处理标签歧义，不建议自动独立分类。

D：30B 15/15，Claude 14/15，质量达到比较线；但这些只是已给两个数的比值，不是 ASCE 7-22 阵风影响系数全流程，也不是 WRF/OpenFOAM 配置综合问答。确定性计算器在这类题上本应是强基线且可避免 LLM 算术错误；未有简单基线实测及真实配置题，不能把 D 整组正式判为“可接走”。把本地模型用于文字定位与解释、把数值交给现有计算器更合理。

## 局限与可复现性

A 标题词泄漏使规则满分；B 25 题集中于 7 篇出版论文、数字/单位较显式，来源页之外图形数字未测；C 20 条单年 NOAA 事件描述及原始 EVENT_TYPE 不一定互相决定；D 只有比值算术，未覆盖真实规范计算/配置。小样本单次温度 0 没有置信区间。Docling CPU 初轮因安装不完整和中途进程 `Cannot allocate memory`，后拆分逐篇转换，失败日志与最终成功文件均保留。vLLM 首轮 v0.13/Torch cu13 ABI 不匹配，修复到 Torch 2.9.0+cu128 后运行；这些准备时间均计入 CU。没有微调。Colab 会话已 stop，最终 sessions 仅显示他人会话。
