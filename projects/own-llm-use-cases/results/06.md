# Silsoe v7 入流—迎风 Cp 时程最小试验

同一单次 LBM-LES 入流实现、正迎风、11 个迎风测点；这里“实测时程”仅指 LBM 目标时程，**不是现场测压验证**。
数据：，只读；引用其 `analyze.py:87-103` 的测点、动压口径。
样本 30001，42–642 s，50 Hz；训练 42–462 s、验证 462–522 s、检验 522–642 s，严格顺序；起始 1.26 s 只作历史窗口。
Cp=(ρ_tap−ρ_REF的因果2 s滑动均值)/(3q)，q=训练段 REF 点的平均 0.5ρ|u|²=0.001279913 格子单位；准定常 U_ref=入口后 1h 排架中心 R_y0_z6 的训练均值 uz=0.05193638 格子速度。
准定常 Cp_mean 仅训练段拟合。线性传递函数：20点×3分量，0–0.9 s 的 0.1 s 间隔十个因果滞后，固定岭惩罚 100；TCN 1.28 s 输入，四层因果膨胀卷积，验证段选择最优 epoch。归一化与选择从不使用检验段。
持续性 Cp(t+Δ)=Cp(t) 只适于提前 Δ 预测；本试验是同步 t 的入流→压力映射，故不列该基线。
