## 必须改（已改）
1. **LLaMat**（三位）：撤回"不采用"。v2 §2.2/图 3：文本抽取 LLaMat 胜所测前沿模型；表格抽取仅略优、商用模型常可比甚至更好，优势主要在 regex 表。采用为**作者自建材料基准上的自述**，模型经继续预训练 30B token 级 + 指令微调 + 下游任务微调；不外推到任意 PDF 抽数，不视为与"前沿模型 + 检索"的公平对比。期刊版（NMI）本人未核到，不引。
2. **MCP 结构分析数字**（A、D）：撤回"<1.5% 属实、纯 LLM >400%"。来源内部口径不一：期刊（Buildings 15(17):3190）摘要 <1.5% 与 >400%，但其表 7–9 有 2.756%/2.834%，纯 GPT 各案例 235–267% 至 >400%；数据论文（Data 10(11):169）给 230–270%。只保留定性："纯 LLM 结构计算不可靠，接求解器后大幅改善"，均为单一课题组自述（审稿人 A、D 核，本人未亲核正文表格）。
3. **NL2FOAM 72B 对照**（A、D）：恢复为来源声称——Dong 等（VNP48R7H，arXiv 2504.09602）在其基准上 88.7% vs Qwen2.5-72B 31.4%；88.7% 是以 L2 误差定义的 solution accuracy，不是成功率；网格仍需人工。
4. **"微调只对固定格式有用"删除**（A）：Ovadia 只比无监督微调 vs RAG；Balaguer 有监督微调 +6 pp。改为"知识注入优先检索；监督微调在有标注的窄任务上可有增益，是否值得看本组实测"。
5. **土木领域先例补 CivilGPT**（A）：同济 CivilGPT 为分阶段预训练 + 微调 + 工程对齐，Civil-Bench 14,823 客观题 + 269 主观题，对比 15 个模型（作者自评）。"土木未见专用 LLM"撤回；风工程仍未见；"有论文新颖性"改为"证据不足"。
6. **PDF <14% 是错置指标**（E、A）：出自 OpenFOAM 文档的页面级检索召回，不是表格/数值抽取；与 OCRBench 不矛盾。补 SciAssess（NAACL Findings 2025，表 3：Llama3.1 与 GPT-4o 表格抽取召回均 0.441，审稿人 A 核，本人未亲核）。
7. **筛选证据重写**（A、D）：补 PMC12657656——Llama 3.3 70B 灵敏度 0.88/特异度 0.93，GPT-4o 0.85/0.97，Gemini 1.5 Pro 0.94/0.85，Claude 3.5 Sonnet 0.94/0.80（亲核）。PMC12873614 低精确率含 GPT-4o mini，不是开源特有；ISPOR 96.3%/89.1% 属整个流程，非单模型。**"本地初筛 + 前沿复核"不能保证召回**：被本地排除的不会被复核找回——评测里必须单独量本地模型的召回。
