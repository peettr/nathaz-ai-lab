## HRRRCast-live 可取得什么

- 官方代码 https://github.com/NOAA-GSL/HRRRCast-live，MIT `LICENSE` 原文：“Permission is hereby granted, free of charge, to any person obtaining a copy of this software and associated documentation files (the "Software"), to deal in the Software without restriction, including without limitation the rights to use, copy, modify, merge, publish, distribute, sublicense, and/or sell copies of the Software”。许可文件在仓库根目录；权重未看到单独许可声明，不能仅以代码许可推定模型权重独立再分发条款。
- 仓库完整 master tree（GitHub API 返回 51 条，`truncated=false`）有，Git LFS 指针 `oid sha256:2edef5a5a32cd31f9a6b89ea0b0a54f36d4c528fc20990645debf9446a9315a5`，标示 203112115 字节（约 203 MB）。公开 HEAD 返回 200、Content-Length 203112115；HTTP Range 0–15 返回 206、Content-Range 0-15/203112115，前 16 字节为 ZIP/Keras 格式头。故不是“只有代码无权重”；匿名读取得到真实权重文件的首段，但未下载整文件或核完整 SHA256，也未加载、推理或测 A100。GitHub release v1 无附件不是无权重证据。 同仓库公开。下载使用 Git LFS/media 地址而非只取 134 字节指针；实际运行前仍需全量下载验 SHA256、装载与依赖适配。
- README 给定输入 HRRR 分析/预报与 GFS 边界、6 km（原 HRRR 隔点，530×900）、逐小时滚动与扩散集合；默认输入 6 个气压层变量×20 层，预测动态场通道数依配置。 第 43 行明确层值 `[200,300,350,400,450,500,550,600,650,700,750,800,825,850,875,900,925,950,975,1000]` hPa；最低气压 200 hPa，不含 100 hPa，因此现行默认配置不能直接抽至 100 hPa 的 L2 探空。不能把“20 层”误写成“到 100 hPa”。NOAA 模型页也称未来 3 km/9 年为计划，不是本权重能力：https://gsl.noaa.gov/hrrrcast/。权重对应训练起止年份尚未从模型文件和公开 README 证实；正式盲测前须核对，不能假定第二轮所选 2022–2026 事件全在其训练期外。
- 的 `compute_wind_gust`（第 464 行起）产出 GUST、GUST_FACTOR、GUST_CONV：GUST 是由 10m 风经验因子、低层最大风与垂直速度增强三者取最大所得的后处理诊断，不是明确经短时阵风真值训练的直接网络输出；默认经验因子 1.4（第 464 行），GUST_CONV 是其对流增强候选（第 543 行），与最终 GUST 不等同。比较时须并列保存两字段，并报告模型及 HRRR GUST 对观测的比，不能称“神经网络直接预测阵风”。
- README/ 有未来 GFS 时次或未来 synoptic cycle 的处理；严格“起报时可用”检验必须审每个 GFS cycle 的发布时间和源 GRIB URL，防止把事件后才发行的场混入真预报条件。当前仅检索代码，未验证此条件。

## 第二轮执行状态

若预算闸门允许正式开跑，HRRRCast 已是有公开权重的候选，应以同批且处于其训练期外的事件/对照、相同时间/空间窗和原判据，与 StormCast 分模型并列评估；成员随机种子与初值固定，GUST/GUST_CONV 两字段分列，报告宽窄窗、窗边比例及两条 HRRR 阵风基线。当前缺完整权重校验、训练期证明、运行时测量与合格事件，因此“可下载权重”不等于“Colab 已跑通”，本轮所有比较门槛未评估。早先 StormCast 第二轮名义预算约 163.4 CU，已越过任务书的 >100 CU 先停回报线；增加 HRRRCast 只会增加未量化工作量，不得自行开整批计算。

## Cook 2023 与观测处理

正式版 Cook, N. J. (2023), *Meteorology* 2(2):276–294, DOI https://doi.org/10.3390/meteorology2020017 （Crossref metadata 的页码也是 276–294；委托中 274–291 与出版信息不符）。摘要/§3.2 将 2014 年前 ASOS 数据模拟施加 Test 10：约 10% 的该研究所选对流阵风事件的峰值会被删除；不是所有当代 ASOS 事件普遍缺峰率，更不能对七例直接作漏峰概率订正。该文结论“recovery of erroneously culled observations is not possible”；IEM 的归档一分钟资料仍是站内 QC 后归档数据，不是可恢复的未质控传感器原始时序。对已报道强风事件保留 METAR/分钟分钟戳核对与缺失疑点，但独立 Mesonet 交叉主要用于无事件对照和“模型报强风而 ASOS 无记录”的情况，以免把漏观测算成模型误报。独立资料不全的对照不得默认标成真阴性。

第一轮统一表述为“所选强风事件里邻域 10 m 风幅值、使用事后 ERA5 条件场的回报”；不得推广为真预报雷暴阵风技巧或一切无事件误报能力。
